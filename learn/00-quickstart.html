Quickstart

Monocurl scenes are ordinary text files. You declare values, place meshes into the scene, then tell the runtime how those values should move.

DEFINITIONA mesh is the visual value that eventually reaches the viewport. Meshes can be points, curves, surfaces, text, images, or trees containing other meshes.

A Minimal Scene

The smallest useful scene imports the standard mesh and animation libraries, creates a mesh leader, and plays an animation.

Set snaps every dirty mesh follower to its current leader value. That makes it the simplest way to show a newly-created object.

Animate By Changing The Leader

To animate, assign a new destination value and play a primitive animation.

The key idea is that code describes states. The runtime handles interpolation between those states. Mesh-aware animations such as Trans know how to match geometry while moving from one mathematical state to the next.

IMPORTANTA play statement is a cache point for the live preview. Keep scenes split into clear play steps so the editor can seek precisely.
