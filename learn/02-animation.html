Animation Model

Monocurl animations are built from state changes. You mutate a leader to the state you want, then play an animation that moves the follower there.

Leaders And Followers

A mesh declaration owns a leader value and a follower value. Code writes the leader. The viewport draws the follower.

Primitive Animations

Set, Wait, and Lerp are the low-level primitive operations. Mesh animation usually uses semantic helpers like Trans, Grow, Fade, and Write, which compose down to those primitives after preparing geometry.

slide "timing"
play Set()
play Wait(0.25)
play Trans(1, rate: smooth)

Mesh-Aware Motion

Animations like Write, Fade, Grow, and Trans know how to prepare mesh geometry before interpolation begins.

IMPORTANTPrefer the semantic animation when one exists. Trans communicates a different intent than a plain Lerp, and that intent gives the runtime room to choose better geometry matching.
