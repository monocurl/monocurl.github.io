Language Tour

Monocurl is a small language, but it is designed around values that can be animated. The syntax is close to Rust in its block structure and close to math in how vectors and transformations read.

Declarations

Use let for immutable bindings, var for ordinary mutable values, mesh for animated leaders, and param for values that can be adjusted during presentation.

let radius = 1
var points = []
mesh graph = []
param phase = 0

Functions

Functions are declared with pipe-delimited parameters.

let ring = |radius, color| fill{color} Circle(radius)
mesh outer = ring(2, BLUE)

Arguments can have defaults, and function values can be passed into constructors that sample callbacks.

Blocks And Slides

Blocks introduce scope. Slides divide a scene into presentation-sized moments.

mesh title = Text("A theorem")

slide "intro"
play Write(0.8)

slide "proof"
title = Text("Proof")
play Trans(0.6)
REMARKA scene can be rendered as one continuous video or stepped through as a slideshow because slides are first-class in the execution model.
