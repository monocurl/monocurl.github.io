Presentations

Presentation mode turns a scene into a live slideshow. The same source can still be exported as a video, but slides become the navigation model.

Parameters

Parameters expose runtime controls. Use them when a presenter should be able to adjust a mathematical value without editing source code.

$radius builds a stateful value. When the parameter changes, dependent mesh leaders can be re-evaluated and the viewport updates.

Camera And Framing

The scene camera is just another value with a special renderer meaning. During presentation mode, camera motion and parameter changes can be coordinated.

mesh camera = Camera(position: [0, 0, -8], target: ORIGIN)

slide "camera"
play Set(&camera)

Writing For Slides

Use a slide whenever the speaker should pause, explain, or expose a new control. Use animation inside that slide to guide attention.

METAA good Monocurl presentation reads like a proof outline: each slide owns one conceptual step, and each animation makes that step visible.
