Mathematical animation,
in code.

Monocurl is an open-source language for creating mathematical animations. Write the states; the runtime handles the transitions.

Start learning Open stdlib

Declarative

Assign a new value to a mesh and play a transition. The runtime determines how to interpolate geometry between mathematical states — no keyframes, no timeline editors.

Mathematical

Meshes are first-class values: curves, surfaces, text, or trees of other meshes. Syntax is close to Rust in structure and close to math in how vectors read.

Live

The editor previews the scene up to the current timestamp as you type. A finished scene renders as a continuous video or steps through as a slideshow.
